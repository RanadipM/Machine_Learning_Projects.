# Portfolio Optimization

This project implements multiple portfolio optimization strategies using Python and Streamlit.

Link -https://machinelearningprojects-4wzhdi8gjxzzubyerwjs2m.streamlit.app/

## Strategies Implemented
- Minimum Variance Portfolio (MVP)
- Hierarchical Risk Parity (HRP)
- Eigen Portfolio

## Features
- Risk-return analysis (Sharpe, Sortino, Calmar)
- Maximum Drawdown & Rolling Metrics
- Portfolio allocation visualization
- Statistical testing (Jobson-Korkie, Ledoit-Wolf)
- Interactive dashboard using Streamlit

## Tech Stack
Python, NumPy, Pandas, Scikit-learn, SciPy, Matplotlib, Streamlit

## Files
- `app.py` → Streamlit dashboard
- `portfolio_optimization.ipynb` → Model development & analysis
