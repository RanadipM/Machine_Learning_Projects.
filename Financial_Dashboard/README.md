# Financial Dashboard - FinAI
Link -"https://huggingface.co/spaces/mannaranadip169/Finiq-v5"

AI-powered financial analytics dashboard built using Python, Gradio, Plotly, and yFinance.  
This project provides real-time stock insights, portfolio analysis, and data-driven investment support.

---

## 🚀 Features

- 📈 Real-time stock analysis using yFinance
- 📊 Interactive financial visualizations (Plotly)
- 💼 Portfolio performance tracking
- 🧠 AI-based insights and recommendations
- 🔍 Comparative stock analysis
- 📉 Risk and return analytics

---

## 🛠️ Tech Stack

- **Programming:** Python
- **Frontend/UI:** Gradio
- **Visualization:** Plotly
- **Data Source:** yFinance API
- **Libraries:** Pandas, NumPy, Scikit-learn
