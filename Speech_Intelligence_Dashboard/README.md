# Speech Intelligence & NLP Dashboard

A Streamlit-based Natural Language Processing dashboard for analyzing speeches using sentiment analysis, topic modeling, and text intelligence techniques.

## Live Application
https://machinelearningprojects-2uizwnxgw8nfojedzhejgl.streamlit.app/

## Features
- Sentence-level Sentiment Analysis using VADER
- Sentiment Trend Visualization
- Word Cloud Generation
- Bigram Frequency Extraction
- Topic Modeling using Latent Dirichlet Allocation (LDA)
- Upload and analyze custom text files

## Technology Stack
- Python
- Streamlit
- NLTK
- Scikit-learn
- Pandas
- Matplotlib
- WordCloud

## Project Overview
This dashboard enables users to analyze historical or custom speeches and extract meaningful insights through natural language processing techniques. It provides visual and analytical tools to understand sentiment patterns, dominant themes, and textual structure within speeches.
